# Ramad Copilot – סייר פיקוד מדורי Multi-Agent

מערכת ניהול וסיוע פיקודי לרמ"ד (ראש מדור) בצה"ל, המפקד על כ-30 חיילים ב-5 צוותים (סדיר, קבע, מילואים, יועצים).  
המערכת מבוססת **Multi-Agent (LangGraph + Gemini Pro/Flash)**, פועלת בענן 24/7 ללא תלות במחשב דולק, וזמינה ישירות דרך **WhatsApp** (טקסט והודעות קוליות) לצד לוח בקרה ויזואלי.

המערכת מעוגנת באופן מלא במסמך התפיסה הפיקודית של הרמ"ד: [`doctrine.md`](doctrine.md).

---

## 🏛️ ארכיטקטורת הסוכנים (Multi-Agent Architecture)

המערכת פועלת באמצעות גרף סוכנים מתואם (**LangGraph**) המורכב מ-4 סוכנים ייעודיים:

1. **Supervisor / Router Agent:** קולט הודעות (כולל תמלול אודיו של הודעות קוליות ישירות מ-Gemini), מזהה כוונות ומנתב לסוכן המתאים.
2. **People & Development Agent:** שולט בכל 30 חיילי המדור ב-5 צוותים, מנטר זמני שחרור, מאזן תפקידי נע"ת (הוואי, Buddy לקליטה, ציוד), מתריע על איחור בשיחות חניכה (מעל 30 יום), ומוודא מיצוי זכויות ת"ש.
3. **Task & Cadence Agent:** מנהל את רשימת התג"בים האישית של הרמ"ד, מונע מריחת משימות, ואוכף את עקרון "מה שלא ביומן לא קורה".
4. **Command Advisor & Sparring Coach (מצפן פיקודי):** מבוסס על `doctrine.md`. בשוטף מסייע בדילמות פיקודיות לפי "מועילות מול יעילות". במצב "אתגר אותי" או בתחקור הדו-שבועי, הופך למאמן סוקרטי שבודק עמידה ב-Red Lines (חוב טכנולוגי שקוף, זלזול, אי-סגירת לו"ז).

## 🚀 הרצה מקומית מהירה

### 1. דרישות מוקדמות
- Python 3.11 או 3.12 (או שימוש ב-`uv`)
- מפתח API של Google Gemini מ-[Google AI Studio](https://aistudio.google.com/)

### 2. הגדרת משתני סביבה
העתק את קובץ הדוגמה והזן את המפתח שלך:
```bash
cp .env.example .env
# ערוך את .env והגדר GEMINI_API_KEY=AIzaSy...
```

### 3. התקנה והרצה
```bash
# יצירת סביבה והתקנת תלויות
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt

# אתחול הנתונים (30 חיילים, משימות ושגרות)
python -m backend.app.db.seed_data

# הרצת השרת
python -m backend.app.main
```
השרת יעלה בכתובת `http://localhost:8000` עם תיעוד Swagger ב-`http://localhost:8000/docs`.

### 4. הרצת בדיקות (Test Suite)
```bash
PYTHONPATH=. pytest tests/test_api.py -v
```

## 📱 חיבור לווטסאפ (Evolution API ב-Docker)

1. הרץ את הקונטיינרים:
```bash
docker-compose up -d
```
2. פתח בדפדפן את ממשק Evolution API: `http://localhost:8080/manager`.
3. צור מופע (Instance) חדש בשם `default`, וסרוק את ה-QR קוד באמצעות הווטסאפ בטלפון.
4. מעתה, כל הודעת טקסט או הודעה קולית שתישלח למספר תעובד ע"י מנוע הסוכנים ותחזיר תשובה תוך שניות!

## ☁️ פריסה לענן מנוהל (Railway / Render - 24/7)

המערכת מוכנה לפריסה בענן מנוהל ללא צורך במחשב מקומי דולק:
1. חבר את ה-Repository שלך ל-[Railway.app](https://railway.app).
2. הוסף שירות **PostgreSQL Database**.
3. הוסף שירות **Dockerfile** מהפרויקט.
4. הגדר את משתני הסביבה:
   - `GEMINI_API_KEY`
   - `DATABASE_URL` (מקושר ישירות ל-PostgreSQL ב-Railway)
   - `RAMAD_PHONE_NUMBER`
5. המערכת תרוץ 24/7, תשלח התראות בוקר ותענה לפניותיך בכל שעה.
